Nebius Token Factory is a platform that provides an OpenAI-compatible API for AI inference and fine-tuning, supporting over 40 open-source models such as DeepSeek, Llama, Qwen, and others, optimized for high-performance hardware [2][6]. It offers production-grade AI inference at scale with features like governance, team and access management, SSO, unified billing, and audit-friendly workspaces [6]. Developers can use it to run models, fine-tune them with datasets, and integrate with third-party tools [1][2].

Developers call Nebius Token Factory using an OpenAI-compatible API by making HTTP POST requests to the API endpoint with the appropriate headers and payload. Authentication is done via a Bearer token in the `Authorization` header, using an API key obtained from the Nebius Token Factory dashboard [2][1]. The API supports standard OpenAI-compatible parameters for generation, such as `model`, `messages`, and `temperature` [4].

To use the API, developers can set the `base_url` to the Nebius Token Factory endpoint and provide their API key via environment variables or directly in the client configuration. For example, using the OpenAI Python client:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.tokenfactory.nebius.com/v1",
    api_key=os.environ.get("NEBIUS_API_KEY")
)

response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1-0528",
    messages=[
        {"role": "system", "content": "You are a helpful assistant"},
        {"role": "user", "content": [{"type": "text", "text": "hello"}]}
    ]
)

print(response.to_json())
```

This code sends a request to the Nebius Token Factory API to generate a response using the DeepSeek-R1-0528 model, using the OpenAI-compatible interface [1][2]. The platform also supports model flavors like `base` and `fast`, which can be specified by appending `-fast` to the model name for optimized performance [4].
